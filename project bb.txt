📖 성경 앱 프로젝트 기획안 (최종본)
1. 프로젝트 개요
* 명칭: 미정 (가칭: 심플 바이블)
* 핵심 가치: 광고 없음, 로그인 없음, 완전 오프라인, 최고의 가독성.
* 대상 플랫폼: iOS, Android (스마트폰 및 태블릿 대응).
* 기술 스택: Flutter, SQLite (FTS5).
2. 데이터 및 DB 설계 (Core)
데이터의 일관성과 검색 성능을 최우선으로 설계합니다.
2.1 Verse UID 체계
모든 번역본의 동일 구절을 연결하는 고유 키를 사용합니다.
* 형식: `BBCCCVVV` (Integer, 총 8자리)
* 예시: 창세기 1장 1절 → `01001001`, 요한복음 3장 16절 → `43003016`.
2.2 테이블 구조
테이블명주요 역할비고`translations`번역본 정보 (개역한글, NKJV 등)언어 및 표시 순서 관리`books`성경 66권의 이름 및 약어Grid 선택창 및 타이틀 표시용`verses`실제 성경 본문 데이터`verse_uid` 기반 인덱싱`fts_verses`FTS5 기반 검색 가상 테이블빠른 텍스트 검색용 (Off-line)`bookmarks`사용자가 저장한 절 정보`verse_uid`와 `translation_id` 참조
3. 주요 기능 상세
3.1 읽기 및 내비게이션
* 그리드형 선택창: 드롭다운 대신 **66권 격자(Grid)**와 숫자 격자를 사용하여 직관적인 권/장 이동을 지원합니다.
* 대조 모드: 단일 번역 모드와 2개 번역 병렬(Parallel) 모드를 제공합니다.
   * 모바일: 상하 병렬 (구절 단위 레이아웃).
   * 태블릿: 좌우 분할 (너비 800px 이상 시 자동 전환).
* 상태 복원: 앱 재실행 시 마지막 읽던 `verse_uid`, 선택한 번역본, 설정된 폰트 크기를 완벽히 복원합니다.
3.2 검색 및 북마크
* FTS5 검색: 인터넷 연결 없이도 수만 개의 절 중에서 키워드를 즉시 찾아냅니다.
* 북마크 관리: 절 단위로 저장하며, 목록에서 클릭 시 해당 위치로 즉시 이동합니다.
* 롱탭(Long-press) 액션: 특정 절을 길게 누르면 '복사' 및 '북마크 추가' 메뉴가 나타납니다.
3.3 사용자 설정 (Customization)
* 서체 옵션: 고딕(시스템)과 명조체(KoPub World 바탕체) 선택 기능을 제공하여 장시간 독서 시 피로도를 줄입니다.
* 다크 모드: 시스템 설정 연동 및 수동 ON/OFF를 지원합니다.
* 가독성 최적화: 태블릿 등 넓은 화면에서는 본문의 Max Width를 제한하여 시선 이동 범위를 최적화합니다.
4. 화면 구성 (UI/UX)
1. 홈 화면: "이어서 읽기" 카드 + 최근 북마크 리스트.
2. 본문 화면: 상단 바(권/장 선택, 번역본 선택, 검색 아이콘) + 본문 영역 + 하단 내비게이션(이전/다음 장).
3. 선택 팝업: 신/구약 탭 분리형 그리드 레이아웃.
4. 검색 화면: 검색창 + 결과 리스트(권:장:절 표시).
5. 설정 화면: 폰트 종류/크기 슬라이더, 다크 모드 스위치.
5. 개발 로드맵 (4단계)
1단계: 데이터 셋업 (가장 중요)
* Python 스크립트를 사용하여 원본 데이터(XML/JSON)를 `verse_uid` 체계의 SQLite DB로 변환.
* FTS5 인덱스 미리 생성 후 Flutter `assets`에 포함.
2단계: 핵심 읽기 UI 구현
* Flutter `sqflite` 패키지 연동.
* 그리드형 권/장 선택기 및 본문 스크롤 뷰 구현.
* 단일/대조 모드 레이아웃 대응.
3단계: 부가 기능 및 최적화
* FTS 검색 엔진 연결 및 결과 화면 구현.
* SharedPreferences를 이용한 설정 값 및 위치 저장.
* 태블릿 반응형 레이아웃(Max Width) 적용.
4단계: 폴리싱 및 배포
* 다크 모드 테마 정밀 조정.
* iOS/Android 아이콘 및 스플래시 화면 제작.
* 스토어 등록용 스크린샷 준비.
