# 성경 (Simple Bible)

광고 없고, 로그인 없고, 인터넷 없이 읽는 성경 앱.

## 설계 원칙

이 앱은 **처음 써 보는 어르신도 설명 없이 읽을 수 있는 것**을 첫 번째 목표로 만듭니다.
그래서 아래 규칙이 다른 모든 것보다 우선합니다.

1. **홈 화면이 없습니다.** 앱을 켜면 곧바로 읽던 자리가 열립니다. 처음 켰다면 요한복음 3장.
2. **누르는 것에는 글자가 붙습니다.** 아이콘만 있는 버튼은 두지 않습니다.
3. **누르는 것은 48dp 이상입니다.** 정확히 못 눌러도 눌립니다.
4. **글자는 크게 시작합니다.** 기본 22pt, 최대 40pt, 행간 1.6.
5. **되돌릴 수 없는 동작을 만들지 않습니다.** 북마크 삭제에는 되돌리기가, 잘못 뛴 자리에는 뒤로가기가 붙습니다.
6. **구절 선택은 짧은 탭입니다.** 길게 누르면 거기까지 범위로 늘어납니다. 아무도 못 찾는 숨은 제스처를 유일한 입구로 두지 않습니다.
7. **말투는 자리에 따라 갈립니다.** 버튼·라벨은 개조식(`이전 장`, `최근 본 곳`, `앞으로 · 요한복음 3장`), 알림·안내 문장은 해요체(`북마크를 지웠어요`). 이동을 문장으로 쓰면 "…으로 돌아왔어요" 같은 군말이 생깁니다 — 화면이 이미 하고 있는 말입니다.
8. **상태를 알리는 데 타이머를 쓰지 않습니다.** 스낵바는 사건에, 줄(bar)은 상태에. 앞으로 가기는 시계가 아니라 "읽기를 다시 시작했다"는 사건으로 사라집니다.

## 화면 구조

```
┌──────────────────────────────────────────────┐
│  [ 요한복음 ▾ ]  [ 3장 ▾ ]      🔍검색  ☰더보기  │
├──────────────────────────────────────────────┤
│                                              │
│   1  태초에 말씀이 계시니라 ...                  │
│   2  그가 태초에 하나님과 함께 계셨고 ...          │
│                                              │
├──────────────────────────────────────────────┤
│   ‹ 이전 장        3장         다음 장 ›        │
│                  전체 21장                    │
└──────────────────────────────────────────────┘
```

- **책 / 장 버튼** — 화면에서 가장 큰 버튼. 가장 자주 쓰기 때문입니다.
- **더보기** — 글자 크기, 번역본, 북마크, 설정. 아이콘을 줄줄이 늘어놓는 대신 한 곳에 모았습니다.
- **구절을 길게 누르면** 북마크·복사 막대가 올라옵니다. 처음 한 번만 안내가 뜹니다.
- **두 손가락으로 벌리면** 글자가 커집니다. 몰라도 됩니다 — 더보기에 같은 기능이 글자로 있습니다.

## 폴더블 / 태블릿

| 화면 너비 | 동작 |
|---|---|
| `< 600dp` | 세로 한 단 (폴드 커버 화면, 일반 휴대폰) |
| `≥ 600dp` | 장을 넘기는 페이지 방식 |
| `≥ 840dp` | 한 장을 좌우 두 단으로 나눔 (펼친 폴드, 태블릿) |

- 접었다 펴도 **보던 장이 유지됩니다.** 부모 화면이 현재 장을 계속 갖고 있다가 새 레이아웃에 넘겨줍니다 (`ReaderScreen._chapter` + `navSeq`).
- `navSeq`는 "일부러 이동했다"는 신호입니다. 페이지를 넘기며 부모로 되돌아오는 장 번호와, 진짜 이동 명령을 구분하기 위한 것입니다. 이게 없으면 읽던 장을 계속 다시 불러옵니다.
- 두 단으로 나누는 기준을 600이 아니라 840으로 둔 이유는, 반쯤 펼친 폭에서 두 단으로 쪼개면 읽기 힘든 좁은 띠 두 개가 되기 때문입니다.
- `AndroidManifest.xml`에 `resizeableActivity="true"`와 `configChanges`에 `screenLayout|smallestScreenSize|screenSize`가 있어야 접었다 펼 때 액티비티가 재시작되지 않습니다.

## 기술 구성

- **Flutter** (SDK 3.0.0 이상)
- **SQLite** (`sqflite`) — 34MB 성경 DB를 assets에서 앱 저장소로 복사해 사용
- **Provider** — `SettingsService`(읽기 설정·위치), `DatabaseService`
- **SharedPreferences** — 글자 크기, 굵기, 테마, 마지막 읽은 위치, 번역본 선택

## 검색

한글과 라틴 문자를 다르게 처리합니다. 이유는 재현율입니다.

| 낱말 | LIKE 결과 | FTS 접두 결과 | 재현율 |
|---|---|---|---|
| 사랑 | 518 | 518 | 100% |
| 하나님 | 3584 | 3584 | 100% |
| love | 547 | 443 | 81% |

한국어는 조사가 뒤에 붙으므로 찾는 낱말이 항상 토큰의 **앞부분**입니다. 따라서 FTS5 접두 검색(`"사랑"*`)이 `LIKE '%사랑%'`와 같은 행을 돌려주면서 26배 빠릅니다. 영어는 `love`가 `beloved`의 중간에 있어 접두 검색으로 놓칩니다.

그래서 **모든 낱말이 한글일 때만 FTS5를 쓰고, 그 외에는 LIKE**를 씁니다 (`DatabaseService.isHangulOnly`). AND/OR 조합은 FTS5의 연산자 우선순위가 이미 AND를 더 강하게 묶으므로 LIKE 경로와 같은 그룹핑이 됩니다.

FTS5가 없는 기기를 위해 첫 사용 시 한 번 탐지하고, 실패하면 조용히 LIKE로 되돌아갑니다.

## 사용자 데이터

북마크는 `user_data.db`에 있습니다. 성경 본문 `bible.db`와 **다른 파일**입니다.

`bible.db`는 assets의 것과 크기가 다르면 통째로 덮어써집니다. 예전에는 북마크가 그 안에 있어서, 성경을 새로 배포하면 사용자 북마크가 전부 사라졌습니다.

예전 설치본에서 올라오는 경우 북마크를 한 번 옮겨옵니다. **덮어쓰기 전에** 읽어냅니다 (`_rescueLegacyBookmarks`) — 순서가 반대면 옮겨올 대상이 이미 없습니다. `meta` 테이블의 표식이 남아서, 사용자가 지운 북마크가 다음 실행 때 되살아나지 않습니다.

## 레이아웃 검증

`flutter analyze`는 오버플로를 못 봅니다. 실제로 그려봐야 나옵니다. `test/layout_test.dart`가 모든 바와 시트를 6가지 폭(320 / 348 폴드 커버 / 411 / 600 / 840 펼친 폴드 / 1280)과 2가지 글자 배율(1.0 / 2.0)로 그려서 오버플로를 테스트 실패로 잡습니다.

이 테스트를 처음 돌렸을 때 **13건이 실제로 넘쳤습니다**. 고정 높이(`height: 56`)와 줄바꿈 못 하는 라벨이 원인이었고, 지금은 `minHeight` + `Flexible` + 배율에 따라 커지는 앱바로 바뀌었습니다. 바에 고정 높이를 다시 넣지 마세요.
